*A jade dragon paperweight that's in a different pose every day.*

## Description

- A small jade paperweight figurine of a dragon.
- Every day it's in a different pose, but nobody has ever seen it move.
- Unique.

## Effect

- If it's cared for and treated with respect, it bestows *Dragon's Blessing*. See [[Spells]].

## Drawbacks

- If it's mistreated or discarded, it bestows *Dragon's Curse*. See [[Spells]].

- Unplaced. The old notes suggest pairing it with the items from [[The Crypt]].
