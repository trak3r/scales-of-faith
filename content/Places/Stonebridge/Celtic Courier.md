*Messages and packages delivered by willing animal companions.*

## Description

Stonebridge's delivery service. Wolves in harnesses run parcels wrapped in twine through the night woods.

## Notable Features

- Message and package delivery by animal companion.
- Working name alternative: *Pegasus Parcel*.

## Inhabitants

- [[Shelt'n]], proprietor.
- Behind the scenes, the shop is run by the [[Courier Druids]].

## Hooks

- **The deadly route.** One delivery route has become too dangerous for overland deliveries: something is hunting and killing the delivery animals. It may be the same dire bear [[Hyde]] wants. See [[Hunt for the Dire Bear]].
